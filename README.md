# Скиллы для Claude Code

- `animated-pptx-deck`: презентация .pptx с переходами Morph, анимациями появления и финальным отдалением, в светлом редакционном стиле.
- `gleb-taste`: мои правила для любого интерфейса: понятность, настоящий интерактив, цифры с характером, без пустот.

Установка: скопировать папку скилла в `~/.claude/skills/`.

Сделано вместе с Claude Code: идея, постановка задачи, проверка и поиск багов мои, код писал агент.
